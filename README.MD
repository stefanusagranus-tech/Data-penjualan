# Data Penjualan Backend API

Backend modern menggunakan **FastAPI** dan **Supabase** untuk mengelola dan menyajikan data laporan penjualan.

## Tech Stack
- Python 3.10+
- FastAPI
- Uvicorn
- Supabase-py

## Konfigurasi Environment Variables
Pastikan variabel berikut diset di environment server atau file `.env` lokal:
- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`
